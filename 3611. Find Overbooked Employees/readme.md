## Quick Overview  
- **Problem Type:** SQL  
- **Difficulty:** Easy / Medium  
- **Key Concept:** Detect overlapping time intervals  
- **Solution:** Use a self-join on the same table (employee, date, start, end) to find pairs of bookings for the same employee on the same date where one booking’s start is before another’s end and vice versa, then pick distinct employees.
