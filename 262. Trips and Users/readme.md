- **Problem Type:** SQL  
- **Difficulty:** Medium  
- **Key Concept:** Aggregate & divide to calculate average cost per trip per user  
- **Solution:** Use `SUM(trip_cost)` / `COUNT(trip_id)` grouped by `user_id` to compute average cost, then pick users whose average cost is *less than* some threshold or condition (as required by the problem).
