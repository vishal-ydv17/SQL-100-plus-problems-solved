## Quick Overview  
- **Problem Type:** SQL  
- **Difficulty:** Easy  
- **Key Concept:** Conditional aggregation (`SUM` with `CASE WHEN`)  
- **Solution:** Sum gains and losses separately using `CASE WHEN transactionType = 'S'` (sell) or `'B'` (buy), group by year and asset type.
