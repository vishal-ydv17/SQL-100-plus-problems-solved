## Quick Overview  
- **Problem Type:** Greedy, Simulation  
- **Difficulty:** Easy  
- **Key Concept:** Iterate through bus arrival times and passenger arrival times  
- **Solution:** For each bus, board as many people as possible in order, track the last boardable passenger time; then derive the latest possible time a new person can arrive to catch a bus by “just before” that last boarded person or exactly when the bus departs if there is a free seat.
